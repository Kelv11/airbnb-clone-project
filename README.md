# Airbnb Clone Project

## Project Overview

This project is a full-stack clone of the popular accommodation booking platform AirBnB. The goal is to build a functional web application that allows users to browse property listings, view detailed property information, and complete bookings. The project will cover frontend development, backend APIs, database design, and deployment.

## What I'll Learn

This project will help me:

- Build responsive interfaces that work on all devices
- Structure a complex web application properly
- Work effectively in a team environment
- Master component-based frontend architecture
- Apply web development best practices

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript with React
- **Version Control:** Git & GitHub
- **Design:** Figma for mockups and UI planning

## UI/UX Design Planning

### My Design Goals

- Create a booking flow that feels intuitive and natural
- Keep visual elements consistent throughout the app
- Optimize for fast page loading
- Ensure everything works well on mobile devices

### Core Features

- Robust property search with various filters
- Detailed property pages with all necessary info
- Streamlined and secure checkout process
- User authentication

### Main Pages

| Page                  | What It Does                                                         |
| --------------------- | -------------------------------------------------------------------- |
| Property Listing View | Shows available properties in a grid with filter options             |
| Listing Detail View   | Displays comprehensive property info with photos and booking options |
| Checkout View         | Simple, clear booking confirmation and payment process               |

### Why User-Friendly Design Matters

The success of any booking platform depends heavily on how easily users can navigate through it. When designing this clone, I'm focusing on reducing friction points that might cause users to abandon their booking journey. Clear visual cues, intuitive navigation patterns, and responsive layouts will help build user confidence and increase conversion rates. The best designs often feel invisible because they just work as expected.

### Figma Design Specifications

#### Color Palette:

- Primary: #FF5A5F (Airbnb's signature coral)
- Secondary: #008489 (Teal accent)
- Background: #FFFFFF
- Main Text: #222222
- Secondary Text: #717171

#### Typography:

- Primary Font: Circular, Medium (500), 16px
- Headings: Circular, Bold (700), 24px-32px
- Supporting Text: Circular, Book (400), 14px

### Why Design Specs Matter

Having clear design specifications helps me maintain consistency throughout the project. When I know exactly which colors, fonts, and spacing to use, I can focus on functionality rather than making design decisions on the fly. This approach helps create a professional-looking product and speeds up development since I'm not constantly switching between coding and design tasks.
